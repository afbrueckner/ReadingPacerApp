Cognitive Reading Pacer — Field Manual

Catholic Middle School Edition • Research-Backed Fluency & Comprehension Protocol

1. Key Metrics & Definitions

WPM (Words Per Minute): Pure physical eye tracking speed across lines of text.

Comprehension %: Accuracy score on post-reading verification quiz ($100\%$ or $50\%$).

ERR (Effective Reading Rate): Calculated as $\text{WPM} \times \text{Comprehension \%}$. This core metric prevents skimming by penalizing speed without retention.

ΔERR (Growth Delta): True cognitive growth measured between standardized Form A and Form B benchmarks.

2. Lexile Bands vs. RTI Support Tiers

To avoid confusion with school Multi-Tiered System of Support (MTSS/RTI) frameworks, the app separates instructional support tiers from text readability bands:

  • Foundational Band (400L – 550L): Grade 4–5 readability; builds core decoding confidence.
  • Intermediate Band (600L – 750L): On-grade Grade 6–7 readability; standard targets.
  • Advanced Band (800L – 950L): Grade 8 / Honors readability; complex syntax.
  • Mastery Band (1000L+): High School / College Ready readability.
  • RTI Tiers (School Level): Tier 1 (Universal 100%), Tier 2 (Targeted 10-15%), Tier 3 (Intensive 5%).

3. The 4 Pacing Modules

1. Standardized Diagnostic (Tab 1)

Establishes baseline ERR using locked static benchmark texts (Form A/B) matching IXL Lexile bands.

2. Accelerator Focus Shutter

Eliminates line regression and vocalization by pacing eyes forward with a moving focus window.

3. Morpho-Visual Flasher

Expands peripheral visual span and foveal fixation width using phrase flashes centered on anchor target letters.

4. PQRST Active Reader

Guides Preview, Question, Read, State, and Test steps for high comprehension retention on faith-aligned AI topics.

4. 15-Minute Classroom Protocol

  1. Diagnostic / Re-Test (3 Mins): Complete Form A (Day 1) or Form B (Progress Check) on Tab 1.
  2. Ocular Span Warmup (3 Mins): Run 20–30 flashes on Module 2 (Visual Flasher).
  3. Speed Pacing (5 Mins): Set Module 1 Focus Shutter to +20 WPM above baseline on a custom topic.
  4. Active Recall & Quiz (4 Mins): Complete Module 3 (PQRST Reader) preview and quiz.
